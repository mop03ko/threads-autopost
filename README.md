# Threads автомат постлогч

Meta-гийн албан ёсны Threads API ашиглан товлосон цагт пост нийтэлдэг хэрэгсэл.
Гуравдагч этгээдийн үйлчилгээ шаардахгүй, үнэ төлбөргүй, Threads-ийн дүрэм зөрчихгүй.

**Данс**: @mop03ko · **Ээлж**: эхний долоо хоногийн 14 пост бэлэн орсон

---

## Сайн мэдээ: App Review шаардлагагүй

Threads апп нь **development горимд** байхад аппын эзэн болон "Threads Tester"-үүд
API-г бүрэн ашиглаж чадна. Та зөвхөн **өөрийн данс руу** пост тавих учир
App Review дамжих шаардлагагүй. Тохируулга 30 минутад дуусна.

App Review нь зөвхөн **бусад хүний** данс руу нэвтрэх аппад хэрэгтэй.

## 1. Meta апп үүсгэх (15 минут)

1. https://developers.facebook.com/apps руу орж **Create App** дарна
2. Use case сонгохдоо **"Access the Threads API"** гэдгийг сонгоно
3. Апп-ын нэрийг өгнө (жишээ: `mop03ko-autopost`). Энэ нэр хэнд ч харагдахгүй
4. Апп үүссэний дараа зүүн цэсээс **Threads → Settings** руу орно

**Тэндээс дараах гурвыг тохируулна:**

**a) Callback URL-ууд (гурвуулаа заавал)**

```
Redirect Callback URLs:  https://localhost/threads-auth
Uninstall Callback URL:  https://localhost/threads-uninstall
Delete Callback URL:     https://localhost/threads-delete
```

Redirect хаягаа бичсэний дараа **Enter дарж** chip болгоно. Үгүй бол форм
хадгалагдахгүй. Гурван талбарын аль нэг нь хоосон байвал мөн хадгалагдахгүй.
Сүүлийн хоёр хаяг ажиллах шаардлагагүй.

**b) Threads Tester нэмэх**

**Roles → Threads Testers** хэсэгт өөрийн `mop03ko` дансаа нэмнэ.
Дараа нь https://www.threads.com/settings/account руу орж
**Website permissions → Invites** хэсгээс урилгыг **зөвшөөрнө**.

Энэ алхмыг алгасвал дараагийн бүх алхам алдаа өгнө.

**c) Threads App ID болон Threads App Secret хуулж авах**

**Threads → Settings** хуудсан дээр байна (App settings → Basic дээрх
ерөнхий App ID БИШ).

Meta апп бүр хоёр өөр багц түлхүүртэй. Threads API нь зөвхөн **Threads**
хуудсан дээрхийг хүлээж авдаг. Буруу нь ашиглавал зөвшөөрөл авах үед
`No app ID was sent with the request` (код 4476002) алдаа гарна.

## 2. Хэрэгслийг суулгах (5 минут)

```bash
cd threads-autopost
pip install -r requirements.txt
cp .env.example .env
```

`.env` файлыг нээж гурван мөрийг бөглөнө:

```
THREADS_APP_ID=1234567890123456
THREADS_APP_SECRET=abcdef0123456789abcdef0123456789
THREADS_REDIRECT_URI=https://localhost/threads-auth
```

> **Анхаар**: `.env` болон `token.json` файлыг хэзээ ч бусадтай хуваалцаж болохгүй.
> Эдгээр нь таны данс руу нэвтрэх эрх агуулна. `.gitignore` дотор аль хэдийн орсон.

## 3. Эрх авах (5 минут)

```bash
python3 threads_post.py auth-url
```

Хэвлэгдсэн холбоосыг браузертаа нээнэ. `mop03ko` дансаараа зөвшөөрнө.

Браузер `https://localhost/threads-auth?code=AQxxxxx...#_` руу шилжинэ.
Хуудас нээгдэхгүй (хэвийн үзэгдэл). **Хаягийн мөрөөс `code=` ба `#` хоёрын
хоорондох текстийг хуулна.**

```bash
python3 threads_post.py exchange --code AQxxxxx...
```

Амжилттай бол `token.json` үүсэж, 60 хоногийн хугацаатай токен хадгалагдана.

### Постоо Google Sheet дээрээс засах

Ээлжийг Google Sheet дээр засаж, скрипт нь тэндээс татаж авдаг болгож болно.
Утаснаасаа ч засах боломжтой болно.

**Нэг удаагийн тохиргоо:**

1. Sheet-ээ нээгээд **Share** дарна
2. **General access** хэсгийг **"Anyone with the link"** → **Viewer** болгоно
3. Хаягнаас Sheet ID-г хуулна. `/d/` ба `/edit` хоёрын хоорондох урт текст
4. `.env` файлд нэмнэ:

```
THREADS_SHEET_ID=таны_sheet_id
```

**Ашиглах:**

```bash
python3 threads_post.py sync          # Sheet-ээс татах
python3 threads_post.py run --sync    # татаад дараа нь нийтлэх
```

**Баганын нэрс** (эхний мөр): `id`, `огноо_цаг`, `бичвэр`, `зургийн_холбоос`, `төлөв`

**Хамгаалалт:**

- Аль хэдийн нийтэлсэн постыг Sheet дарж бичихгүй. Дахин нийтлэгдэх эрсдэлгүй
- Буруу огноо, хоосон бичвэртэй мөрийг алгасаж, анхааруулга өгнө
- Огнооны олон хэлбэрийг таньдаг (`2026-08-20 08:30`, `8/20/2026 8:30 PM` гэх мэт)
- Татахын өмнө `queue.bak.json` нөөц үлдээнэ

> Sheet нь холбоостой хүн бүрт харагдана. Доторх нь удахгүй нийтлэх постууд
> тул мэдрэмтгий мэдээлэл байхгүй. Гэхдээ энэ хуудсанд нууц зүйл бичихгүй.

### Хоцорсон постыг гараар нийтлэх

Компьютер унтарсан, эсвэл цаг өнгөрсөн тохиолдолд скрипт постыг автоматаар
алгасдаг (90 минутын хамгаалалт). Гараар нийтлэх хоёр арга бий.

**Тодорхой нэг постыг яг одоо нийтлэх** (хамгийн найдвартай):

```bash
python3 threads_post.py list                  # id-г нь олно
python3 threads_post.py run --live --id 1
```

Хуваарь, хоцролт, `hold` төлөв бүгдийг үл тоож нийтэлнэ. Хэд хэдэн постыг
зэрэг өгч болно: `--id 1 4 7`

Аль хэдийн нийтэлсэн постыг дахин нийтлэхээс татгалзана.

**Хоцорсон бүх постыг нийтлэх**:

```bash
python3 threads_post.py run --live --force
```

Нэг удаад 3 постоос ихгүй нийтэлнэ. Ирээдүйн постуудад хүрэхгүй.

> `--force` нь олон постыг дараалан нийтэлж болзошгүй. Threads богино
> хугацаанд олон пост тавихад хүрээг бууруулдаг тул `--id` ашиглах нь
> ихэвчлэн дээр.

## 7. Автоматжуулах (cron)

Постууд 08:30 ба 20:30-д товлогдсон тул скрипт 10 минут тутам ажиллаж,
хугацаа нь болсныг нийтэлнэ.

```bash
crontab -e
```

Дараах хоёр мөрийг нэмнэ (**зам болон Python-ы байршлыг өөрийнхөөрөө солино**):

```cron
# 10 минут тутам хугацаа болсон постыг нийтэлнэ
*/10 * * * * cd /ЗАМ/threads-autopost && /usr/bin/python3 threads_post.py run --live >> cron.log 2>&1

# Сар бүрийн 1-нд токеныг сунгана (нөөц хамгаалалт)
0 9 1 * * cd /ЗАМ/threads-autopost && /usr/bin/python3 threads_post.py refresh >> cron.log 2>&1
```

Замаа мэдэхгүй бол `pwd`, Python-ы байршлыг `which python3` гэж шалгана.

> `run` тушаал өөрөө токеныг шалгаж, 10 хоногоос бага үлдсэн бол автоматаар
> сунгадаг. Дээрх сарын cron нь зүгээр нэг нэмэлт хамгаалалт.

## Зурагтай постын тухай

Threads API нь **шууд зураг байршуулахыг дэмждэггүй**. Зураг нь урьдчилан
интернэтэд нээлттэй HTTPS хаягтай байх ёстой.

Сонголтууд:

- Өөрийн вэб сайт эсвэл хостинг
- Cloudinary, imgbb зэрэг үнэгүй зураг хостинг
- GitHub repo дээр тавьж raw холбоосыг ашиглах

Ээлжинд байгаа 4 пост (`o` тэмдэгтэй) зураг хүлээж байна. Зургаа байршуулаад
`queue.json` дотор `image_url`-г бөглөж, `status`-ыг `pending` болгоно.

## Алдаа засах

**`OAuthException: Invalid platform app`**
Threads Tester урилгыг зөвшөөрөөгүй байна. 1-b алхам руу буцна.

**`redirect_uri does not match`**
`.env` доторх хаяг Meta апп дээрх хаягтай яг таарахгүй байна. Ташуу зураас,
`http` vs `https` хүртэл ижил байх ёстой.

**`Token has expired`**
60 хоног өнгөрсөн. 3-р алхмыг дахин хийнэ.

**Пост тавигдахгүй байна**
```bash
tail -30 cron.log
python3 threads_post.py doctor
python3 threads_post.py list
```
Компьютер унтарсан эсэхийг мөн шалгана.

**`ModuleNotFoundError: requests`**
```bash
pip install -r requirements.txt
```

## Хязгаарлалт

- Threads API нь **thread (олон постын цуваа)** үүсгэхийг хязгаартай дэмждэг
- Комментод автоматаар хариулах нь `threads_manage_replies` эрх шаардана (энэ хэрэгсэлд ороогүй)
- Компьютер унтарсан үед пост тавигдахгүй. Тогтвортой ажиллуулах бол хямд VPS ашиглана
- Хоногт 250 пост, 1000 хариултын API хязгаартай (бидний хэрэглээнээс хол давсан)
